# The Last Lantern v0.7.0 — Motion and Soul Engine test build

This revision preserves the approved Hollow Sanctuary art direction and addresses the v0.6 device-playtest feedback.

- Articulated enemy locomotion, committed axe lift/downswing/contact/recovery, grounded impact cracks and debris, and reusable movement profiles.
- New sword poses with measured weapon sockets; damage, animation and trails share one attack clock. Fine flame/smoke replaces the blocky booster effect.
- Authored water, masonry and hanging platforms; visible energy emitters replace ambiguous steam. The lever, wards and projectiles now share the sanctuary materials.
- Automatic paired portals with dormant destinations and protection against immediate return transport.
- An optional Bellbeast encounter within this chapter, collectible persistent boss souls, Soul Engine upgrades, visible Lantern Plate armor and a raven summon.
- Top-edge pause/settings/equipment, offline thematic fonts, compact edge notices and dialogue, and shorter menu labels.

The application ID and persistent signing certificate are unchanged, so this build updates the previous signed test installation and preserves its saves. Version code 8.

Validation evidence is separated into unit/simulation tests, legal-input campaign routes, isolated visual fixtures and Chromium touch/UI smoke. This remains a debug prerelease: physical Android comfort, frame rate, thermals, audio mix and commercial readiness require device and human playtesting. Generated strips still have limited frame counts; matching idle or recovery poses are reused where documented in the motion manifest.
